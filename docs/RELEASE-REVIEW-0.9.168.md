# 配布前レビュー対応（0.9.168）

## 変更理由と範囲

| 対象 | 変更理由 | 置換・追加した処理 | 確認が必要な箇所 |
|---|---|---|---|
| SlotAppearance.Tick | モデルを解決できないスロットでは通常の待機条件を通過し、毎フレーム検索・警告出力していた。 | マスタが利用可能な場合だけ失敗を記録し、既存の見た目を復元する。同じ設定では再試行せず、別の設定をBindしたときに解除する。マスタ未準備・空の場合は失敗を確定しない。 | 無効なモデル名からのバニラ表示、警告の抑制、有効な見た目への変更後の復帰。 |
| ClosedTentProbe.Apply | 見た目用の複製がPrefabのColliderを保持していた。 | 複製したテント内のColliderを無効化。元のテントは操作しない。 | 閉店中のテント表示と歩行・接触、開閉店・マップ再入場。 |
| PresetUiController.OnDeleteChoice | 削除結果を保存できないと無通知で一覧に戻っていた。 | 成功時は削除完了、失敗時は既存save.failed通知を表示。どちらも閉じた後はスロット一覧へ戻る。 | 削除失敗時の通知、閉じる操作、データ保持、通常の削除とキャンセル。 |
| README | 旧導入手順がDLLのみの配備を案内していた。 | 現行の導入・操作・保存先・復旧・削除手順を記載。旧文書はREADME-HISTORY.mdへ保存。 | 配布ZIPにDLL・日英JSON・READMEが含まれること。 |

マスタのモデル定義は同じプロセス内では変わらない前提。実行中に別Modがマスタへモデルを追加するケースは、設定の変更またはゲーム再起動で再判定する。失敗キャッシュに通常の非同期モデル読み込み失敗は含めない。

現在のみため・プリセットの保存形式は変更しない。今回のコードはバニラのセーブデータ、実配置・実効果データを書き換えない。
