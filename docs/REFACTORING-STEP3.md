# 第3段階: デバッグパネルの削除

2026-09-22。公式UIに移行済みの操作とデバッグ専用表示を削除する。
保存形式、プリセット操作、現在のみための保存、モデル適用・復元の仕様は維持する。

| 削除・置換 | 不要と判断した理由 | 置換先・残すもの | 壊れる可能性がある箇所 |
| --- | --- | --- | --- |
| PrototypeDriver.OnGUI、Prototype.Drawとデバッグパネル | 公式UIへの操作移行が完了。デバッグUI削除の対象 | 通常操作は既存の公式UIを使用 | 保存・読み込み・削除、名前入力とキャンセル |
| PanelControls、PanelTextInputとビルド登録 | パネル専用のボタン・文字入力処理 | 既存の公式選択肢・名前入力 | 公式入力経路に削除対象の参照がないこと |
| 検索、候補キャッシュと列挙、見た目巡回、プリセット巡回、旧パネル保存、ON/OFF切替 | パネルからだけ呼ばれる操作とデータ | 公式スロット一覧・みため編集を維持。診断用ON/OFF操作は削除 | 全カテゴリでの選択、プリセット保存先 |
| パネル用の名前・メッセージ・未保存フラグ・折りたたみ状態 | 描画先がなくなる | 終了確認の変更判定は既存のスナップショット比較を維持 | 変更あり/なしの終了確認と3択 |
| SlotRuntimeのActual/Visual/Status表示、RefreshLabelsと名前検索 | デバッグ用ラベル以外で使用しない | モデルの状態管理、安全検証、復元、警告は維持 | 編集終了・開閉店・マップ遷移後のモデル表示 |
| NativeDecorUi.Drawのデバッグ表示とnote | デバッグ専用文言は不要。ただし描画内に通常UIの更新が含まれていた | RefreshPresentationとして分離し、PrototypeDriver.LateUpdateから独立したGuardで呼ぶ | ヘッダー・フッター、名前/説明欄と効果欄の表示タイミング |

## 挙動に関わる変更点

通常UIの表示更新は、ゲームのUpdate後・描画前に実行するLateUpdateへ移した。
従来の「編集画面とdraftが存在し、編集中である」という呼出し条件を維持する。
OnGUIと完全に同じタイミングではないため、以下の実機確認が必要。
既存の着地アニメーション用LateUpdate処理は残し、表示更新とは別のGuardで保護する。

保存処理とschema 9は変更しない。CurrentAppearance・プリセット・復旧用データを維持し、設定ファイルの削除や移行は不要。
バニラのセーブ・実効果データへの書き込みは追加していない。

## 検証

- Releaseビルド: 警告0、エラー0。
- IdentityChecks: 75項目成功。
- 削除したパネルAPI・入力処理・ラベル更新への参照が残っていないことを検索で確認。
- ゲーム内動作は未確認。自動チェックはUnity UIの表示タイミングを検証しない。

実機での確認項目:

1. 右上のデバッグパネルが表示されない。
2. みためモードへの切替・タブ切替で名前と説明が表示され、効果欄が隠れる。通常編集へ戻ると表示が復元する。
3. ヘッダーとフッターが、確認ダイアログ表示・キャンセル・画面再表示で従来どおり切り替わる。
4. プリセット保存・名前入力・読み込み・削除と、キャンセル・完了通知を閉じる操作が使える。
5. 変更あり/なしでの編集終了と3択、ホバー/着地姿勢の維持が変わらない。
