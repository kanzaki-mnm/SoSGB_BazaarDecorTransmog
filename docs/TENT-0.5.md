# テント試作 0.5.1

編集画面・開店中の Tent / index 0 を、小オブジェと同じ外見指定の対象に追加。
公式一覧の Appearance mode と、MOD パネルの Tent ボタンから選択できる。
実際の配置・効果の指定は変更せず、描画用モデルを別に生成する。
適用直前・直後に配置と取得可能な効果値を比較する。実機確認は未実施。

## 今回の範囲

- 小オブジェ4枠＋テント1枠を同じプリセットに保存。
- 旧 schema 1 は読み取り可能。Save preset 時に schema 2 を保存し、直前のファイルを .bak に残す。
- schema 2 は旧 DLL では読めない。旧版へ戻す場合は別途保管した旧プリセットも戻す。
- 非DLCかつ静的メッシュだけで構成されたモデルが対象。対応外は理由をパネルに表示。
- Appearance mode OFF で Editor preview も OFF になる挙動を維持。
- 開店用の元モデルが非アクティブになったら、外見モデルを除去する（最大約0.5秒間隔）。

## 平時・閉店モデル

`BazaarMyShopClosed.PartsObject.LoadParts` と、その保持する `m_PartsObject` が別に存在する。
既存ログでは通常テントのモデル名と静的メッシュは確認できたが、閉店用の実体・読込規則は未確認。
**0.5.0では平時モデルの差し替えは行わない。平時に元のテントが出るのは想定どおり。**

今回追加した `ClosedTentTracked` / `ClosedTentState` は、実際の閉店モデル名、ID、親子構造、
コンポーネント、アクティブ状態の変化を記録する。Diagnostics.Enabled=false でも採取する。
これを使い、閉店用Prefabや付属物の扱いを次の段階で決める。

## 実機確認

1. ゲームを終了し、DLLを入れ替えて起動する。
2. 通常フィールドで自店の閉店状態を表示する。
3. オブジェ編集画面を開き Appearance mode を ON。テント一覧から外見を選択・決定する。
4. Appearance mode OFF で元のテントに戻ることを確認。ONに戻し、Save preset。
5. バザール開店中に差し替えを確認。Transmog OFF/ON で復元・再適用を確認。
6. お店を閉じるか通常フィールドへ戻り、開店用の外見モデルが重なって残らないことを確認。
7. 再起動後のプリセット復元を確認し、今回の LogOutput.log をプロジェクト直下へコピーする。

ビルド：警告0・エラー0。ID解決／保存／旧形式の読み込みを含む管理コードテスト28件成功。
ゲーム内のモデル切替やネイティブUIの動作は、上記の実機確認が必要。

## 0.5.0 実機結果（2026-09-17）

- テントの要求7回・適用7回。全適用で配置と取得可能な効果値の前後比較が一致。
- `DiagnosticError` は0件。プリセット保存も成功。
- 編集画面・開店中の差し替え、ON/OFF、閉店時の開店用モデル除去を目視確認。
- 閉店側は `BazaarMyShopClose(Clone) / TentSpace / fld_cst_009_02(Clone)` の2階層。
- `TentSpace` の表示状態は実際の遷移に沿って `true → false → true` と変化した。
- 閉店側が保持するモデル名は開店側と同じだった。別名の閉店専用Prefabを読み込む構造ではない可能性が高い。
- `m_PartsObject.Item1` はIL2CPPのValueTupleラッパーから正しいIDを取得できていないため、ログ上の巨大な数値は装飾IDとして使わない。実配置IDは `BazaarManager.CustomData` から取得する。

## 0.5.1 閉店中テント試作

- 保存中または編集中の Tent 外見を、`TentSpace` 配下の閉店テントにも適用する。
- 閉店側のValueTuple内IDは使わず、`BazaarManager.CustomData` の Tent / index 0を実効果IDとして照合する。
- 元の閉店テントは削除せずRendererだけを隠し、選択した静的Prefabを同じ親・位置に複製する。
- 開店中は親の `TentSpace` と一緒に非表示になり、開店側の差し替えだけが表示される。
- Transmog OFF、Use vanilla、プリセット変更、モデル再読込、MOD終了時には元Rendererを復元する。
- `ClosedTentTransmogApplied` の `unchanged: true` で実配置IDが適用前後に変化していないことを確認できる。

確認項目：通常フィールドで閉店テントの見た目、開店時との切替、Transmog OFF/ON、
Use vanilla、プリセット切替、編集画面を開閉した後の再表示。新しい `LogOutput.log` も保存する。

## 0.5.1 実機結果（2026-09-17）

- 閉店中のテント外見差し替えに成功。
- Transmog ON/OFFで指定外見とバニラ外見を相互に復元できた。
- 開店してから再び閉店した後も、閉店用の指定外見が再適用された。
- テント部分だけが指定外見になり、樽・棚・荷物など別カテゴリの配置物は維持された。
- パネルに残っていた旧診断文言 `closed tent not overridden` は、汎用の待機表示へ修正した。
