# UI整理 0.8.1

この版では変更画面を開くと自動でみため編集へ入る。0.9.0以降のモード切替は
[MODE-0.9.md](MODE-0.9.md) を参照。

## デバッグパネル

- ゲーム起動後は `-` を押した状態、つまり折りたたみ表示から始まる。
- `+` で従来のプリセット操作とデバッグ用Transmog ON/OFFを展開できる。
- Transmogの初期値は従来どおりON。設定ファイルの値は維持される。

## 公式編集画面

Transmog ONで外見編集に入ると、左上の公式タイトルを次のように一時変更する。

- 日本語: `オブジェの変更` → `みための変更`
- English: `Redecorate` → `Change Appearance`
- 文字色: 通常の濃茶色 → 紫系
- 背景色: 公式の背景スプライトを維持したまま、薄い紫系のTintを適用

タイトルと背景は公式の `UIPageHeader.headerText` / `UIPageHeader.bg` 参照から取得する。
対応する元文言が日本語またはEnglishと一致した場合だけ変更し、別のテキストを推測で変更しない。
画面終了、Transmog OFF、ページ切替では元の文言・文字色・背景色へ戻す。

タイトルを特定できた場合、従来の左下 `Official decor list` 案内欄は表示しない。
特定できないUI構成では案内欄をフォールバックとして残し、ログに
`NativeModeTitleNotFound` を記録する。成功時は `NativeModeTitleFound` に実際の階層を記録する。

## 実機確認

1. 起動直後、デバッグパネルがタイトルバーだけの折りたたみ状態か確認する。
2. Transmog ONで公式編集画面を開き、左上が紫系背景の「みための変更」になるか確認する。
3. 左下の旧案内欄が消えているか確認する。
4. BackでTransmog OFFにし、「オブジェの変更」と元の色へ戻るか確認する。
5. `+` でパネルを展開し、デバッグ用ON/OFFが従来どおり動くか確認する。
6. 編集画面を閉じて再度開き、タイトル切替が繰り返し正常に動くか確認する。
7. English版では `Change Appearance` になり、左下のフォールバック案内が消えるか確認する。
