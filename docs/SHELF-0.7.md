# 陳列台試作 0.7.1

`Shelf` の3枠を外見指定の対象に追加した試作です。

## 位置

- index 0: Left
- index 1: Center
- index 2: Right

MODパネルの `Shelves`、またはTransmog ON中の公式「オブジェの変更」画面から外見を選択します。

## 安全な差し替え方式

陳列台Prefabには棚の外観だけでなく、商品スロット、商品アイコン、価格表示、販売ポイント、
Colliderなどの機能が含まれます。そのため、外見Prefab全体は複製しません。

実配置Prefabのルートにある棚本体の `MeshFilter.sharedMesh` と
`MeshRenderer.sharedMaterials` だけを外見候補の値へ一時的に差し替えます。
「ワイドなカウンター」のようにPrefabルートがラッパーになっている場合は、ルート直下で
Prefabと同じ名前を持つMeshノードを棚本体として扱います。
子階層は生成・削除・非表示化せず、Transmog OFF時には退避したMeshとMaterialを復元します。
閉店中の別インスタンスにも同じ処理を行います。

公式一覧に表示され、ゲームがモデルを読み込める所持済みDLC外見も使用できます。

## プリセット

schema 4で、小オブジェ4枠・テント1枠・大オブジェ3枠・陳列台3枠を同時保存します。
schema 1～3は読み込み時にメモリ上で移行し、保存するまで元ファイルを書き換えません。

## 実機確認

1. 開店中にLeft / Center / Rightへ別々の外見を設定し、位置対応を確認する。
2. 商品が陳列されたまま表示され、各商品を通常どおり選択・購入できるか確認する。
3. Transmog OFFで元の棚へ戻り、ONで外見が再適用されるか確認する。
4. 編集画面のプレビュー・決定・Use vanillaを確認する。
5. 閉店後の中央陳列台に設定した外見が反映されるか確認する。
6. プリセットを保存し、再起動後に3枠が復元されるか確認する。
7. `LogOutput.log` をプロジェクト直下へコピーする。

ログでは開店中に `ShelfTransmogApplied`、閉店中に `ClosedShelfTransmogApplied` が出ます。
`unchanged:true` は配置IDと取得可能な効果値が差し替え前後で一致したことを示します。

## 0.7.0実機結果

- 3枠の位置対応、商品陳列、商品購入が正常。
- おうえんタイム中の中央陳列台にも外見が適用された。
- ログでは開店中121回、閉店中54回の適用がすべて `unchanged:true`。
- 診断エラー0件。
- ワイドなカウンターは棚Meshがルート直下の同名子ノードにあることを確認し、0.7.1で対応。
- にんにんカウンターは `dlcId:1008` に対する試作版の明示的除外が原因で、0.7.1で解除。
