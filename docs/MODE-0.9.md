# 編集モード分離 0.9.19

## 状態

### Transmog ON

保存された外見を通常時・開店中・閉店中へ適用する全体設定。
公式変更画面を閉じてもONのまま維持される。

### 実配置・実効果編集

公式「オブジェの変更」画面を開いた直後の状態。

- 実際に配置されているオブジェを表示する。
- 公式一覧の決定操作は、従来どおり実配置と効果を変更する。
- 既存の `店舗情報を確認 / View stall info` はそのまま利用できる。
- 画面右下へ `X みためを変更 / Edit Appearance` を追加する。
- キーボードではゲーム標準の同操作キー（現在の既定表示はF）で切り替えられる。

### みため編集

右下の `X みためを変更 / Edit Appearance` 操作で入る。キーボードでは同じ公式メニュー操作に割り当てられたキーを使う。

- 保存済みTransmog外見を表示する。
- カーソル移動で外見をプレビューし、決定でプリセット下書きへ反映する。
- 対象タブを切り替えると、公式の水色選択矩形も対象オブジェへ移動する。
- 次の外見が準備できるまで現在の外見を維持し、実効果モデルの瞬間表示を防ぐ。
- 選択中の外見を短い補間で滑らかに持ち上げ、対象を離れると滑らかに戻す。
- 決定時は補間を止め、公式の着地アニメーション・エフェクト・効果音を再生する。
- タイトル、背景、風船アイコンを紫系へ変更する。
- 追加操作は `X 効果を変更 / Edit Effects` に変わり、押すと実配置・実効果編集へ戻る。
- 戻る操作でも実配置・実効果編集へ戻る。Transmog全体はONのまま。
- 実配置と効果データは変更しない。

実配置・実効果編集でもう一度戻ると、公式の通常処理で変更画面を閉じる。
画面を閉じると、フィールド上では保存済みTransmog外見が再適用される。

## 実機確認

1. Transmog ONの状態で変更画面を開く。
2. 最初は通常色の「オブジェの変更」で、実配置モデルが見えることを確認する。
3. `店舗情報を確認 / View stall info` が従来どおり動くことを確認する。
4. 右下の `X みためを変更` を押し、紫系の「みための変更」とTransmog外見へ切り替わることを確認する。
5. 選択中の1オブジェだけが公式どおり浮き、ほかのオブジェが浮かないことを確認する。
6. テント・棚・オブジェの対象タブを切り替え、水色の選択矩形が毎回その対象へ移動することを確認する。
7. 対象タブや一覧項目を続けて切り替え、実効果モデルが途中で一瞬表示されないことを確認する。
8. 選択対象だけが少し浮き、決定時に地面へ着地して効果音とエフェクトが出ることを確認する。
9. `X 効果を変更` を押し、通常タイトルと実配置モデルへ戻ることを確認する。
10. 再びみため編集へ入り、戻る操作でも実効果編集へ戻ることを確認する。
11. もう一度戻り、変更画面が閉じることを確認する。
12. フィールドへ戻った後、Transmog外見が再適用されることを確認する。
13. 実効果編集で配置を変更し、確定後も効果が正常に反映されることを確認する。
14. 日本語・Englishの両方でフッター文言を確認する。
