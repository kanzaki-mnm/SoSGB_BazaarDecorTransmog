# Bazaar Decor Transmog

『牧場物語 Let's！風のグランドバザール / STORY OF SEASONS: Grand Bazaar』の自店舗のオブジェについて、実効果を維持したまま見た目を変更するModです。

対象はテント1枠、陳列台3枠、小オブジェ4枠、大オブジェ3枠です。現在のみための保存と、6スロットのプリセット保存・読み込み・削除に対応しています。Mod独自の表示は日本語・英語に対応し、それ以外の言語では英語を使用します。公式のオブジェ名などはゲームの言語設定に従います。

## 制約

外見を反映するには、その場所の実効果側にもオブジェが配置されている必要があります。実効果側が「配置しない」の場合、Modで外見を指定しても表示されません。

## 導入・更新

Windows版と、ゲームに対応したBepInEx 6のIL2CPP環境が必要です。BepInExが起動する環境に導入してください。

1. ゲームを終了します。
2. 配布ZIP内の `BazaarDecorTransmog.dll`、`README.md`、`i18n` フォルダを、ゲームフォルダの `BepInEx/plugins/BazaarDecorTransmog/` に配置します。
3. ゲームを起動します。

配置例:

```text
BepInEx/
  plugins/
    BazaarDecorTransmog/
      BazaarDecorTransmog.dll
      README.md
      i18n/
        ja.json
        en.json
```

更新時はDLLと翻訳ファイルを一緒に差し替えてください。同名のDLLを別の場所に重複配置しないでください。`BepInEx/config/` の保存データは更新時に削除する必要はありません。

## 操作

自店舗の「オブジェの変更」画面から、フッターの「みためを変更」（Xボタン）で外見編集へ入ります。キーボードやボタン割り当てを変更している場合は、画面下部のガイドに従ってください。

各場所で次の設定を選べます。

| 設定 | 動作 |
|---|---|
| オブジェのみためを指定 | 実効果側のオブジェを変更しても、指定したみためを使用します。 |
| 現在のオブジェのみためを使う（追従アイコン） | 実効果側のオブジェに合わせてみためも変わります。 |
| 表示しない | その場所のみためを非表示にします。陳列台では選べません。 |

一覧で決定すると、その設定を編集中のみために採用します。B／Escで戻ると、変更がある場合は終了確認が表示されます。

| 選択肢 | 動作 |
|---|---|
| 反映してもどる | 現在のみためをMod専用データに保存して戻ります。再起動後も維持します。 |
| 反映しないでもどる | 今回の外見編集を破棄し、編集開始時のみためへ戻します。 |
| やめる | 外見編集を続けます。 |

## プリセット

外見編集のフッターにある「プリセット」（＋／Tab）から保存・読み込みを選びます。スロット一覧の「削除」（Y／左Shift）では確認後に選択スロットを初期化します。

- 保存: 編集中のみためを名前付きで保存します。同じ名前を複数のスロットに使用できます。
- 読み込み: 保存済みのみためを編集画面へ読み込みます。空きスロットの決定では何も起きません。
- 削除: 選択したプリセットだけを削除します。現在のみためは変更しません。

右側の一覧で、固定のみためはオブジェのアイコンと名前、追従する設定は追従アイコンと「現在のオブジェのみためを使う」で表示します。

プリセット保存と「現在のみため」の保存は別です。読み込んだプリセットを再起動後も使うには、「反映してもどる」で現在のみためを保存してください。プリセットの保存・削除はその場で保存され、外見編集の「反映しないでもどる」では取り消されません。

## 保存先

ゲームフォルダの `BepInEx/config/BazaarDecorTransmog.cfg` に、現在のみため（CurrentAppearance）、プリセット、前回の正常状態をまとめて保存します。拡張子は `.cfg` ですが、中身はJSON形式です。通常はゲーム内UIから操作してください。

`BazaarDecorTransmog.cfg.bak` はファイル全体を読み込めない場合の復旧に使用します。復旧可能な過去の状態がある場合は、その状態を読み込み、ログに記録します。復旧時には直近の変更が戻ることがあります。

保存先はゲームのセーブスロットごとには分かれていません。同じMod導入環境では現在のみためとプリセットを共有します。バニラのセーブデータや実効果データへは書き込みません。

## 保存できない場合

「保存できませんでした。詳しくはログをご確認ください。」が表示されたら、B／Escで通知を閉じられます。現在のみため・プリセット保存の失敗後は編集へ、削除の失敗後はスロット一覧へ戻ります。失敗した変更は保存されません。「反映しないでもどる」で外見編集を終了することもできます。

ゲームフォルダの `BepInEx/LogOutput.log` で、次の文字列を探してください。

| ログ | 意味・対処 |
|---|---|
| `PresetFileError` | 起動時に保存データを読めませんでした。破損、対応していない保存形式、読み込み権限などを確認してください。 |
| `CurrentAppearanceSaveError` / `PresetUiSaveError` / `PresetUiDeleteError` | 書き込みに失敗しました。続く `error` に原因があります。ファイルを使っている他のアプリ、書き込み権限、空き容量を確認してください。 |
| `PresetUiSaveRejected` / `PresetUiDeleteRejected` | 保存操作を受け付けられませんでした。先に出ている `PresetFileError` なども確認してください。 |
| `AppearanceDataRecovered` | 過去の正常状態から復旧しました。現在のみためとプリセットの内容を確認してください。 |
| `TransmogSkipped` | 指定したモデルが見つからないなどの理由で適用できませんでした。別のみためを選び直してください。 |
| `DiagnosticError` | Modの処理中に例外が発生しました。再起動でも続く場合は、操作手順とログを添えて報告してください。 |

たとえば `invalid start of a value` はJSONとして読み取れないデータ、`newer Mod version` は現在のModより新しい形式のデータを示します。原因が分からない場合は、ログと発生した操作を添えて報告してください。

ゲームが突然終了し、`LogOutput.log` に原因が残っていない場合は、`BepInEx/ErrorLog.log` が作成されていれば、その内容も確認・報告してください。

復旧できない破損データや、対応していない新しい形式は自動で上書きしません。新しいModで保存されたデータなら、その形式に対応するバージョンを使用してください。

初期状態からやり直す場合:

1. ゲームを終了します。
2. `BepInEx/config/BazaarDecorTransmog.cfg` と `BazaarDecorTransmog.cfg.bak`（存在する場合）を、両方とも別フォルダへ退避します。
3. ゲームを再起動します。

これで現在のみためとプリセットが初期化されます。退避したファイルは保管してください。バニラのセーブデータを操作する必要はありません。書き込み権限や空き容量が原因の場合は、それも解消してから再起動してください。

## アンインストール

ゲーム終了後、`BepInEx/plugins/BazaarDecorTransmog/` のDLLを取り除くとModは動作しなくなり、通常のみために戻ります。翻訳ファイルと、`BepInEx/config/` 内のMod専用 `.cfg`・`.cfg.bak` も不要なら退避または削除できます。保存したみためを残す場合はデータを保管してください。

## 開発資料

ビルドには.NET SDKと、ゲーム環境の `BepInEx/core`・`BepInEx/interop` が必要です。

```powershell
dotnet build .\BazaarDecorTransmog\BazaarDecorTransmog.csproj -c Release
dotnet run --project .\tests\IdentityChecks\IdentityChecks.csproj -- catalog-1.5.0-ja.json
```

ゲーム配置先が異なる場合は、ビルドに `-p:GameDir="ゲームの絶対パス"` を指定します。ビルドはゲームフォルダへ自動コピーしません。

調査・設計資料はリポジトリの `docs/`、過去のREADMEは `docs/README-HISTORY.md` にあります。自動テストは保存・ID照合・復元処理が対象で、ゲーム内の描画や入力は実機確認が必要です。
